# Anshul Tyagi — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract `anshul-portfolio.zip`.
2. Open the `anshul-portfolio` folder.
3. Double-click `index.html` to open it in a browser.
4. For a better development workflow, open the folder in VS Code and run it with the Live Server extension.

## Before publishing
- Add your PDF resume at `assets/Anshul-Tyagi-Resume.pdf`.
- Review the descriptions for EventTwin, ReUseHub, Fixpilot, PantryWise, and DocuTrack. They are starter descriptions based on project names, not verified feature lists.
- Replace each project's GitHub link with its actual repository URL when available.
- Confirm your email, GitHub, and LinkedIn links are correct.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `anshul-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for the Pages deployment to finish and open the published URL shown there.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, themes, animations
- `script.js` — typing effect, theme switch, mobile menu, reveal animations
- `assets/` — place your resume PDF here


Profile photo: `assets/anshul-tyagi.jpg` is used in the home section. Keep this file in place when deploying the site.
